# 立规则: 新任务不挤旧任务

**Why**: 2026-05-07发生2次——讨论UI时Phase 2完全消失,讨论Web修复时Phase 1.5完全消失。每次新话题都把旧任务挤出上下文。

**How to apply**:
1. 任何新规划必须列出与已有Phase的关系(并行/依赖/互斥)
2. 每次汇报状态时,必须列出所有Phase的当前状态(不是只报当前Phase)
3. 新建任务时,必须在todo列表中保留所有未完成Phase的追踪
4. 老唐提到新需求时,先回答"这个和已有的Phase 1.5/Phase 2的关系是X",再展开讨论
5. CEO的全局任务注册表中,所有Phase必须同时可见
