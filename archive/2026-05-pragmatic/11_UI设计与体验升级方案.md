### 对标基准

| 基准 | 学什么 | 我们的差距 |

| **Notion** | 极简,功能不牺牲美感 | review.html 5182行,功能堆砌 |

| 维度 | 目标 | 现状 |

## 四、我想到你可能没想到的(6项)

### 1. 微信小程序——用户在哪,产品就在哪

**为什么不只是网页**: 四川乡镇干部90%的时间在微信里。让他们打开浏览器输URL→必然失败。让他们在微信里点一下→可能成功。

**方案**: 
- 核心QA功能做微信小程序(搜索→提问→看答案→分享)
- 小程序内嵌webview加载复杂页面(课程/合规自检)
- 公众号菜单→小程序,朋友圈分享→小程序
- 微信支付直接在小程序内完成

### 2. PWA离线能力——农村网络不稳定

**为什么**: 乡镇干部经常在项目现场(田间地头),信号不好。不能因为没网就不能用。

**方案**:
- Service Worker缓存核心页面+最近50条QA答案
- 离线时: 显示缓存的QA,新问题排队,有网后自动发送
- 离线标识: 明确告诉用户"当前离线,以下为缓存内容"

### 3. 语音输入——降低使用门槛

**为什么**: 很多乡镇干部年龄偏大(40-55岁),打字慢。但他们习惯发微信语音。

**方案**:
- QA输入框旁加"语音"按钮→调用微信语音识别→转文字→搜索
- 微信小程序原生支持语音识别(免费)
- 网页端用Web Speech API(浏览器自带)

### 4. 一键分享——病毒传播引擎

**为什么**: 乡镇干部之间互相转发政策解读是最自然的获客方式。

**方案**:
- 每个QA答案底部"分享给同事"按钮
- 微信分享卡片: 问题标题+AI回答摘要+logo
- 被分享人点击→直接看到答案→底部"我也要问"→注册转化
- 追踪: 谁分享了?带来了多少新用户?

### 5. 打印友好——政府工作需要纸质件

**为什么**: 乡镇干部需要拿着纸质材料去开会、汇报、存档。纯屏幕=不实用。

**方案**:
- 每个QA答案+合规报告+政策日报支持"打印"/"导出PDF"
- 打印样式: 去掉导航/按钮,只留内容+来源引用
- PDF带页眉(logo+日期)和页脚(来源声明)

### 6. 大字体+高对比度模式——适老化

**为什么**: 40-55岁用户的老花眼比例高。小字=无法使用。这是政策要求(国务院《互联网应用适老化及无障碍改造专项行动方案》)。

**方案**:
- 默认最小字号14px(手机端16px)
- 顶部"字体大小"A-/A/A+三档切换
- 高对比度模式(黑底白字)选项
- 符合工信部适老化标准(不是可选,是合规要求)

## 五、执行规划

### 决策: 作为Phase 1.5,在Phase 2之前执行

**理由**: UI是用户直接接触的,比后端能力(Phase 2的知识图谱/对抗验证等)更紧迫。产品上线前必须有世界级的UI,不然技术再强也没人用。

### Phase 1.5 任务(4条并行线)

| 线 | 内容 | 工时 | 依赖 |
|----|------|------|------|
| **UI-1** | SkillScout UI方向侦察(GitHub找5类工具) | 2h | 无 |
| **UI-2** | 设计系统建立(CSS变量token+颜色/字体/间距/圆角) | 3h | 无 |
| **UI-3** | QA产品页重设计(mobile-first,语音,分享,打印) | 4h | UI-2 |
| **UI-4** | 微信生态规划(小程序评估+JSSDK集成+PWA) | 3h | 无 |

### 与Phase 2的关系

```
Phase 1.5(UI) ──→ Phase 2(能力建设)
    │                   │
    ├─ 设计系统         ├─ 知识图谱
    ├─ QA产品页         ├─ 评测基准  
    ├─ 微信/PWA         ├─ 语义安全
    └─ SkillScout拓展    └─ 4新Agent
```

**两个Phase可以部分重叠**: UI-2(设计系统)完成后,Phase 2的知识图谱/评测基准等可以开始(它们不依赖UI)。

### Agent配置

| Agent | 职责 | 来源 |
|-------|------|------|
| ui_visual_designer | 设计系统+视觉规范 | 研发中心 |
| frontend_architect | ES5实现+性能优化 | 研发中心 |
| mobile_specialist | 移动端+小程序+PWA | 研发中心(已解冻) |
| chinese_nlp_scout | UI工具+微信生态工具侦察 | 研发中心(SkillScout) |
| product_manager | 用户体验标准+转化优化 | CEO办公室(新招) |
