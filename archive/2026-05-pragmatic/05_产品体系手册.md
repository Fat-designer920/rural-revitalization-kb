## AI政策问答助手(第一优先级)

### 产品形态
- 4板块输出: 直答 + 政策依据 + 延伸思考 + 补漏提醒
- 老唐风格: "像旁边坐了个20年老师傅"
- 来源可追溯: 每条引用→KP ID + 源文件 + 置信度
- "我不知道"边界: 不确定就说不知道

### 定价
| 版本 | 价格 | 功能 |
|------|------|------|
| 基础版 | ¥19.9/月 | 50次/月 + 政策速查 + 1个领域 |
| 专业版 | ¥99/月 | 无限问答 + 政策对比 + 案例库 + 5个领域 |
| 专家版 | ¥199/月 | 全功能 + 合规自检 + 指标测算 + 15领域 |

### 做扎实标准
1. 检索: 语义搜索,>90% recall@20
2. 回答: 老唐风格,4板块完整
3. 溯源: 每条引用可追溯
4. 反馈: 每次问答→自动评分→持续优化
5. 边界: 不知道就说不知道
6. 体验: <5秒响应,移动端友好

## 商业模式
- 目标: 月收入¥25万+
- 路径: QA助手基础(¥19.9×2000人) + 专业版(¥99×500人) + 专家版(¥199×200人) + 录播课 + 合规 + 日报 + 模板
- 一人公司: 老唐14小时/周 + 55个AI Agent替代15-20个岗位

## 护城河
1. 老唐20年经验(独家IP,AI不可替代)
2. 四川政策深度(地域壁垒)
3. 用户行为数据飞轮(使用越多→越精准)
4. 客户关系锁定(方案定制+培训+服务)
5. 品牌=四川乡村振兴第一知识工具
