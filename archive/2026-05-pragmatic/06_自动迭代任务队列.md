# 自动迭代任务队列

> AuditEngine 自动生成 + Claude 手动消费。产品驱动：课程体系→知识需求→缺口→管道→闭环。

## 产品驱动管道(知识工厂核心逻辑)

```
课程体系(5模块20课) → 81项知识需求 → 缺口分析(对照KB)
    ↓ 缺口
爬虫定向抓取 + 测试文件喂料 → 提取(并行双模型) → 质检 → 关系网络 → 精品判定
    ↓ 闭环
审计评分 → 新任务 → Claude迭代 → 再审计
```

**铁律**: 所有知识收集必从产品需求倒推，禁止"什么都有"式盲目收集。

## 任务类型说明

| 类型 | 含义 | 动作 |
|------|------|------|
| feed | 知识缺口→需补充内容 | 老唐喂经验 / 爬虫定向抓取 / 测试文件喂料 |
| structure | 知识结构缺陷 | AI生成缺失类型的知识点 |

## 优先级

- **P0**: 阻塞性(崩溃/安全/核心功能缺失/知识库为空的关键领域)
- **P1**: 高优先级(P0完成后处理,质量缺陷/重要功能/关键数据)
- **P2**: 常规优化(体验改进/边缘场景/长期建设)
