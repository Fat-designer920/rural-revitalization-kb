# 立规则: 系统思维 — 触类旁通,举一反三

**Why**: 2026-05-07,老唐提到爬虫skill整合,CEO就只搜索爬虫skill。老唐批评:"我只是举例说到爬虫,你就只思考爬虫,那其他我没说到的呢?比如提升问答助手的skill?提高内容生产质量的skill?"

**How to apply**:
1. 老唐提到一个问题 → CEO必须思考:所有同类问题是否也存在?
   例: 爬虫skill缺失 → QA skill? 内容生产skill? 自动化skill? 安全skill? 全部扫描
2. 每发现一个缺口 → 列出所有相关领域的缺口 → 一次性全部解决
3. "说到一个,解决一类"不是口号,是CEO的核心能力
4. 在CEO的_systematic_scan()中增加跨域检查: 每发现一类问题,自动扫描所有相关域
