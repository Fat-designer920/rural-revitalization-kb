# 立规则: 新要求不终止运行任务

**Why**: 2026-05-07,老唐指出新要求提出后,CEO不应该停止正在运行的任务,除非有冲突或老唐明确说"停"。

**How to apply**:
1. 老唐提新要求 → 加入规划任务队列 → 与现有任务并行跑
2. 只有两种情况可以停:
   a. 新要求与正在运行的任务有冲突(修改同一个文件/访问同一个资源)
   b. 老唐明确说"停"/"暂停"/"停下来"
3. 默认行为: 继续当前任务 + 新要求加入队列一并执行
4. 如果判断可能有冲突 → 报告老唐"这个和正在运行的X任务有冲突,是否停X?"
