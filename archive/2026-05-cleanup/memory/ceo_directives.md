## 3. GitHub Skill 招聘Agent
- 新Agent类型: SkillScout (技能侦察员)
- 职责: 搜索GitHub上有价值的开源skill/tool → 评估商业价值 → 安全性审查 → 整合建议
- 原则:
  a. 必须有利于项目实现商业价值最大化
  b. 必须有利于构建护城河体系(独家IP/数据/方法论/用户关系)
  c. 禁止整合有毒/恶意/未审核的skill
  d. 所有整合前必须经过安全双门禁(SafetyFilter+HallucinationGuard)
  e. 优先级: 中文NLP > 政策分析 > 知识图谱 > 语义搜索 > 爬虫 > UI
- 招聘数量: 2-3个SkillScout Agent, 编入研发中心
