# 乡村振兴知识库

> 20年乡村振兴实战经验的结构化知识底座，面向知识产品变现的核心引擎。

## 这是什么

一套本地运行的知识管理系统，用于从政策文件、项目案例、操盘经验、工具模板、行业数据中**自动提取、结构化存储、人工审核**结构化知识点。

系统定位不是"文档管理工具"，而是**知识产品的生产底座**——所有提取和标注都围绕"如何高效变现"来设计。

## 面向谁

**知识库的建设者**：拥有深厚行业经验的乡村振兴咨询专家，需要将分散在文档、脑袋、聊天记录中的知识系统化。

**知识产品的目标客户**：
- 工程咨询与规划设计公司（投标、方案、评审）
- 地方政府与村级组织（项目申报、合规操作、汇报）
- 施工企业与项目经理（指标核算、验收标准、资料整理）

## 核心能力

**AI驱动提取**：DeepSeek R1深度推理模型逐段分析文件，自动提取知识点并打标。

**三层标签体系**：
- 第一层：6组41个分类标签（业务领域/项目阶段/知识形态/客户视角/稀缺度/内容状态）
- 第二层：8个维度的属性标签（政策层级/资金渠道/涉及主体/区域/时效等）
- 第三层：AI自由提取5-15个关键词

**变现元数据**：每条知识点标注就绪度（草稿/可引用/精品）、权威度（官方/权威/实证/交流）、变现分级（开放/标准/高级）。

**人工审核闭环**：Flask本地Web界面，支持三层标签编辑、就绪度调整、物理删除、批量操作、编辑历史回滚。

## 技术栈

| 组件 | 选型 |
|------|------|
| 运行环境 | Windows + Python 3.8+ |
| AI引擎 | DeepSeek API（R1推理 + V3快速） |
| 本地存储 | SQLite（13张表） |
| 审核界面 | Flask本地Web应用 |
| 操作方式 | 双击.bat文件 |
| 封装方式 | 便携版（绿色免安装） |

## 工作流程

```
文件放入 data/pending/
    |
预处理（AI重命名+分类）
    |
知识提取（R1深度推理 + 三层标签 + 元数据建议）
    |
人工审核（三层标签编辑 + 就绪度/权威度调整）
    |
知识库（结构化存储，支撑产品生产）
```

## 快速开始

1. 双击 `配置向导.bat` —— 填入DeepSeek API Key
2. 双击 `一键初始化.bat` —— 创建数据库和文件夹
3. 将待处理文件放入 `data/pending/`
4. 双击 `处理新文件.bat` —— AI预处理
5. 双击 `提取知识点.bat` —— AI提取知识点
6. 双击 `启动审核界面.bat` —— 打开浏览器审核

## 项目结构

```
scripts/              Python脚本
  |- config_wizard.py    配置向导
  |- setup.py            一键初始化
  |- file_reader.py      多格式文件读取
  |- deepseek_client.py  DeepSeek API封装
  |- preprocessor.py     智能预处理
  |- extractor.py        知识提取引擎
  |- api_server.py       Flask审核界面
  |- db_manager.py       数据库管理
  |- tag_config.py       标签体系配置
  |- check_system.py     系统检查
  |- prompts/            Prompt模板

web/templates/        审核界面HTML
data/                 数据目录
  |- pending/           待处理文件入口
  |- processing/        预处理中
  |- completed/         提取完成归档
  |- failed/            提取失败隔离
  |- database/          SQLite数据库
config/               配置文件
```
