# 🌾 乡村振兴知识库搭建助手

> 本地智能化知识萃取系统 | Local Intelligent Knowledge Extraction System

## 项目简介

将乡村振兴领域的原始资料（政策文件、案例报告、项目材料、Excel表格等），通过 AI 半自动化处理，经人工审核确认后沉淀为结构化知识库。

本系统面向乡村振兴领域的咨询从业者，以"一人公司"模式运营知识付费业务，核心方向包括全域土地综合整治、川西林盘保护修复运营等。

## 核心功能

- **智能预处理**：AI 自动重命名文件 + 打标签（领域、文件类型、地域、政策层级）
- **知识提取**：按5种文件类型使用专业 Prompt 模板提取结构化知识点
- **人工审核**：本地 Web 界面逐条审核、编辑、确认入库
- **安全保障**：API Key Fernet加密存储、每日费用上限保护、白名单路径校验

## 工作流程

```
原始文件 → data/pending/
    ↓ 双击"处理新文件.bat"
AI预处理（重命名+标签） → data/processing/
    ↓
AI提取知识点 → SQLite（待审核）→ data/completed/
    ↓ 双击"启动审核界面.bat"
人工审核（本地Web界面） → 确认入库
```

## ⚠️ 安全说明

本仓库是公开仓库，但以下敏感内容**已通过 .gitignore 排除，不会出现在仓库中**：

| 排除内容 | 原因 |
|---------|------|
| `config/settings.json` | 包含加密后的 API Key |
| `config/encryption.key` | Fernet 加密密钥 |
| `*.db` 数据库文件 | 用户的知识库数据 |
| `data/` 文件夹 | 用户的原始资料文件 |
| `.env` 环境变量 | 可能包含明文密钥 |

如果你 fork 或参考本项目，请务必确认你的 `.gitignore` 正确配置后再推送代码。
