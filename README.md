# 乡村振兴知识库 (Rural Revitalization Knowledge Base)

> 面向四川市场的乡村振兴领域知识管理系统，服务于B端付费内容产品和C端问答助手订阅。

## 当前版本：v2.1.0-c（提取质量加固·已完成）

## 系统定位

这不是一个普通的文档管理工具，而是一个**知识工厂**——将行业文件、政策法规和20年实战经验加工成可变现的知识产品。

**核心竞争力：** 每一条知识点都有入库质检、人工审核、政策验证、定期保鲜的完整质量链。500条精品级知识 > 5000条草稿级内容。

## 商业化场景

| 场景 | 客户群 | 产品形态 |
|------|--------|---------|
| 政策解读订阅 | 乡镇干部/小型咨询公司 | 新政策解读+操作建议+月报 |
| 问答助手订阅 | 基层干部/施工项目经理 | 微信小程序/网页问答 |
| 行业培训课程 | 县级自然资源局/咨询公司 | 线下培训+线上课件 |
| 投标方案辅助 | 工程咨询公司/规划设计院 | 投标素材包自动生成 |

## 功能概览

### 已完成
- **知识提取引擎**：DeepSeek R1模型，V3预分析+三级智能分段+上下文接力+跨段补漏+V3质检
- **三层标签体系**：6组41个分类标签 + 8维度属性标签 + AI自由关键词
- **审核界面**：Flask Web应用，标签编辑+全文搜索+质检排序+物理删除+批量操作
- **备份恢复**：一键备份/恢复，SQLite原生backup API
- **架构升级迁移**：规则检查+AI补标签+重提取调度
- **系统检查v2.0**：12项全面检查+知识库健康度+质检覆盖率

### 开发中
- **v2.1.0-d**：内容保鲜提醒 + 政策依赖校验

### 规划中
- **v2.2.0**：对话式经验录入 + 知识导出 + 手动录入
- **v2.3.0**：知识关联网络 + 场景化检索 + 信息采集 + 冲突检测

## 技术栈

| 组件 | 技术 |
|------|------|
| 运行环境 | Windows + Python 3.8+（便携版） |
| AI引擎 | DeepSeek API（R1推理模型 + V3辅助模型） |
| 数据库 | SQLite（13张表） |
| Web界面 | Flask |
| 操作方式 | 双击.bat文件 |

## 快速开始

### 1. 首次配置
```
双击 首次配置.bat
```
按提示输入DeepSeek API Key，系统自动完成初始化。

### 2. 日常使用流程
```
处理新文件.bat     → 智能预处理（AI重命名+分类建议）
一键提取.bat       → 知识提取（预分析+分段+提取+质检）
启动审核界面.bat   → 人工审核（浏览器打开）
```

### 3. 维护工具
```
一键备份.bat       → 数据库备份
一键恢复.bat       → 备份恢复
系统检查.bat       → 12项全面检查
审核统计.bat       → 审核反馈分析
一键知识库升级.bat → 架构升级迁移
```
