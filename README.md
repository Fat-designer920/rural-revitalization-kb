# 乡村振兴知识库搭建助手

> 本地智能化知识萃取系统 — 20年乡村振兴实战经验的数字化底座

## 系统简介

基于 DeepSeek R1 深度推理模型的本地知识管理系统，专为乡村振兴领域设计。将政策文件、项目案例、操盘经验、实操工具、数据资料等五类文档，智能提取为结构化知识点，构建可检索、可复用、可变现的专业知识库。

**当前版本：v2.1.0-b**

## 核心特性

- **AI深度提取**：DeepSeek R1 推理模型逐段精读，提取高质量知识点
- **三层标签体系**：分类标签(41个) + 属性标签(8维度) + 关键词(自由提取)，支撑多维检索
- **知识元数据**：就绪度/权威度/变现分级/内容保鲜，面向产品化管理
- **Web审核界面**：Flask本地应用，三层标签可视化编辑，批量操作，全文搜索
- **一键操作**：所有功能通过双击.bat文件完成，零编程门槛
- **安全保障**：API密钥加密存储，每日费用上限，一键备份恢复，架构升级迁移
- **便携部署**：绿色免安装，U盘可运行，无需管理员权限

## 系统定位

知识库是未来知识产品的生产底座和核心护城河：
- **B端**：付费课程、操盘指南、深度分析文章、投标方案参考
- **C端**：问答助手订阅制（面向乡镇干部、基层项目经理）
- 当前聚焦四川市场

## 技术栈

| 组件 | 技术选型 |
|------|---------|
| AI引擎 | DeepSeek API（R1推理模型 + V3通用模型） |
| 运行环境 | Windows + Python 3.8+ |
| 数据库 | SQLite（13张表） |

## 工作流程

```
文件投入 → 智能重命名 → [V3预分析] → R1深度提取 → [V3质检] → 人工审核 → 知识入库
   ↓                                                              ↓
data/pending/                                              审核界面编辑
   ↓                                                       三层标签+元数据
data/completed/                                            → 知识产品生产
```

## 快速开始

### 环境要求
- Windows 10/11
- Python 3.8+（推荐3.10+）
- DeepSeek API Key

### 安装步骤
1. 下载或克隆本仓库
2. 双击 `一键配置.bat`，按向导输入API Key
3. 双击 `一键初始化.bat`，创建数据库和目录
4. 双击 `一键系统检查.bat`，确认所有组件正常

### 使用流程
1. 将待处理文件放入 `data/pending/` 目录
2. 双击 `一键预处理.bat`，智能重命名文件
3. 双击 `一键提取.bat`，AI深度提取知识点
4. 双击 `一键审核.bat`，打开Web审核界面
5. 在浏览器中审核、编辑、确认知识点
