# 乡村振兴知识库搭建助手

> 基于DeepSeek R1推理模型的专业知识库构建工具，面向四川乡村振兴领域

## 当前版本：v2.2.0（资产沉淀 + bugfix）

## 系统定位

这不是一个普通的文档管理工具，而是一个**知识工厂**——将行业文件、政策法规和20年实战经验加工成可变现的知识产品。

**核心竞争力：** 每一条知识点都有入库质检、人工审核、政策验证、定期保鲜的完整质量链。500条精品级知识 > 5000条草稿级内容。

## 商业化场景

| 场景 | 客户群 | 产品形态 |
|------|--------|---------|
| 政策解读订阅 | 乡镇干部/小型咨询公司 | 新政策解读+操作建议+月报 |
| 问答助手订阅 | 基层干部/施工项目经理 | 微信小程序/网页问答 |
| 行业培训课程 | 县级自然资源局/咨询公司 | 线下培训+线上课件 |
| 投标方案辅助 | 工程咨询公司/规划设计院 | 投标素材包自动生成 |
| 合规自检工具 | 施工企业/项目经理 | 在线自检+整改建议 |
| 数据查询与测算 | 工程咨询/规划设计 | 指标数据查询+费用测算 |

## 功能概览

### 已完成
- **知识提取引擎(v2.1.1)**：R1/V3双模型8步提取流程，含举一反三推导、V3质检6维度评分
- **知识审核管理(v2.1.2)**：管理后台双Tab架构，仪表盘10卡片+工具箱8按钮+提取管理
- **专家注解(v2.2.0)**：5种注解类型(同意/不同意/补充/纠错/经验)，审核时内联添加，agree自动标注"老唐实战验证"
- **经验速记(v2.2.0)**：3分钟极简表单，V3自动结构化入库
- **扫描件PDF OCR(v2.2.0)**：硅基流动Qwen2.5-VL-72B视觉模型，逐页渲染识别
- **预处理markdown缓存(v2.2.0)**：预处理保存.md缓存，提取时优先读取，消除双重OCR
- **三层标签体系**：6组41个分类标签 + 8维度属性标签 + AI自由关键词
- **智能分段**：V3结构摘要 > 本地规则(章节标记) > 段落边界，上下文接力+跨段补漏
- **保鲜提醒**：定期扫描+审核界面提醒+续期+批量续期+标记过时
- **政策依赖校验**：V3扫描政策引用+知识库匹配验证
- **重复检测**：本地粗筛+V3精判，5种关系类型(重复/版本更替/互补/冲突/无关)
- **备份恢复**：一键备份/恢复，SQLite原生backup API
- **架构升级迁移**：规则检查+AI补标签+重提取调度
- **版本重提取**：按Prompt版本批量重提取+长任务后台执行
- **系统检查v2.5**：16项全面检查+知识库健康度+质检覆盖率

## 技术栈

| 组件 | 技术 |
|------|------|
| 运行环境 | Windows + Python 3.8+（便携版，绿色免安装） |
| AI引擎 | DeepSeek API（R1推理模型 + V3辅助模型） |
| OCR引擎 | 硅基流动API（Qwen2.5-VL-72B视觉模型） |
| 数据库 | SQLite（15张表） |
| Web界面 | Flask（管理后台，Apple风格+Pantone 2026配色） |
| PDF渲染 | pymupdf |
| 操作方式 | 管理后台为主，4个bat入口辅助 |

## 快速开始

### 1. 首次配置
```
双击 配置向导.bat
```
按提示配置DeepSeek API Key和硅基流动API Key。

### 2. 初始化
```
双击 一键初始化.bat
```
自动创建数据库和目录结构。

### 3. 日常使用
```
1. 将文件放入 data/pending/ 目录
2. 双击 启动后台.bat → 打开管理后台
3. 在管理后台 Tab 2 进行：
   - 文件预处理（智能重命名+分类建议+.md缓存）
   - 知识提取（R1提取+V3质检+增量重复检测）
4. 在管理后台 Tab 1 进行：
   - 人工审核（逐条确认/编辑/删除）
   - 专家注解（同意/补充/纠错等）
5. 在管理后台 Tab 2 经验速记：
   - 随时记录碎片化经验，V3自动结构化入库
```

### 4. 维护工具（管理后台 Tab 2 工具箱）
- 系统检查：16项全面检查
- 一键备份/恢复备份
- 保鲜扫描：检查过期知识点
- 全库重复检测
- 政策补跑：补充政策依赖校验
- 审核统计：审核反馈分析
- API费用详情：费用趋势+分类明细

## 双API架构

| 硅基流动 | 扫描件PDF和图片的OCR识别 | Qwen/Qwen2.5-VL-72B-Instruct | 约4元/百万token |
