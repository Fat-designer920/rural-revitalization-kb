## 客户画像(v2.3.6-design 重锚定)

> v2.3.2 L1/L2/L3 三档表(党委书记/项目经理/返乡青年)废弃 — SaaS 三档定价反推的角色泛称与老唐真实业务脱节(立规则 9 第 25 次应验同根)。本节按老唐口述真实业务画像重写。商业化路径见 00_项目全景.md。

### 主体读者(单一锚点,不分档)

**基层一线的操盘手 + 相关人员**——正在做乡村振兴项目、不系统懂、迫切需要在不懂的时候问到靠谱答案的人。

| 维度 | 描述 |
|------|------|
| 状态特征 | 在做、不懂、需要懂(行为状态,不是组织角色) |
| 涵盖范围(开放定义) | 政府基层人员(乡镇/村)、平台公司项目经理、规划院/咨询公司操盘手、施工运营企业、新入行操盘助理、转行从业者 |
| 时间紧迫度 | 高(出问题就来查、查到要能直接用) |
| 答案期望 | "像旁边坐了个 20 年老师傅在告诉我",不是百度百科答案 |

### 老唐的差异化资产(两条腿)

| 资产类型 | 内容 | 替代性 |
|---------|------|--------|
| **操盘经验** | 20 年实战的方法、踩过的坑、反常识洞察、客户沟通话术 | AI 替代不了(独家 IP) |
| **政策的真实理解** | 不是政策原文,而是"老唐怎么看 + 怎么落地 + 避什么坑 + 上面要什么" | 部分可被 AI 加工,但需老唐判断锚点 |

### 知识点期望(P0-P4 优先级,反推 prompt 改造方向)

| 优先级 | 知识形态 | 说明 |
|-------|---------|------|
| **P0 最高** | 操盘方法 / 反常识洞察 / 踩坑记录 / 客户沟通话术 | 老唐独家 IP,AI 替代不了 |
| **P1 高** | 政策的真实理解(怎么落地 + 避坑 + 上面要什么) | 老唐对政策的判断 |
| **P2 中** | 实战案例 / 数据支撑 / 工具模板 | 有用但不是差异化 |
| **P3 低** | 政策原文条款的复述 | 基层能查到原文,过度提取就是 211 条 kp 暴增元凶 |
| **P4 不提** | 纯口号 / 表态语言 / 上级要求复述 / 流程套话 | 完全不入提取 |

## 分类与标签的关系
- 分类体系 = 知识的"档案柜"（按来源类型分区）
- 标签体系 = 知识的"多维标注"（按用途、形态、客户、稀缺度标注）
- **客户画像 = 知识的"读者锚点"(v2.3.6-design 重锚定为基层操盘手单一画像,不再分 L1/L2/L3 三档)**
- 三者并行：一条知识点既属于某个分类，又带有多个标签,且面向单一画像读者(基层操盘手 + 相关人员)
