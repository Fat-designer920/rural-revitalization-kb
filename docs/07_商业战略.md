# 商业战略 — 月收入 ¥200,000 路线图

> CEO保守预测,基于四川市场,四线产品体系

## 产品体系

### 产品线1: 政府端 — "乡村振兴智能合规助手"
- 产品: SaaS平台,含政策合规检查、项目预审、指标测算、案例对标
- 定价: ¥20万/年(月费~¥1.8万),含10个账号
- 客户: 县自然资源局/农业农村局/发改局
- 月收入目标: **¥80,000** (4个县级单位)
- 获客: 省自然资源厅推荐目录 + 试点县示范 + AI生成定制化政策合规报告作敲门砖

### 产品线2: 企业端 — "乡村振兴项目全周期管理工具"
- 产品: 增减挂钩/高标准农田/生态修复模块的项目管理+合规+测算
- 定价: ¥12万/年(月费~¥1万),含5个账号
- 客户: 地方城投/平台公司/规划院/咨询公司
- 月收入目标: **¥60,000** (5个企业客户)
- 获客: 四川土地学会/规划协会推荐 + 招投标信息自动抓取+项目匹配

### 产品线3: 个人端 — "乡村振兴知识宝典·个人版"
- 产品: AI知识问答+政策速查+每日一课
- 定价: ¥199/月,年付¥1999(首年优惠¥999)
- 客户: 村支书/乡镇干部/驻村工作队/独立咨询师
- 月收入目标: **¥30,000** (~150人×¥199/月)
- 获客: 微信视频号每周直播 + 公众号 + 村支书裂变 + 免费PDF合集引流

### 产品线4: 培训/课程 — "乡村操盘手实战训练营"
- 产品: 线下2天集训 + 线上课程会员 + 企业内训
- 定价: 线下¥3980/人,线上会员¥499/季度,企业内训¥5-8万/场
- 客户: 县局科长/乡镇分管领导/平台公司中层
- 月收入目标: **¥30,000** (1期线下集训 + 线上会员 + 企业内训分摊)
- 获客: 省市党校/干部选学菜单嵌入 + 免费线上精品课引流
