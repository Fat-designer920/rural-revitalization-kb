# 页面导航架构与路由设计

> 核心原则: 管理后台是Hub,可进入所有页面。产品页面是Spoke,不可进入管理后台。

---

```
                    ┌─────────────────────────┐
                    │   管理后台(review.html)   │

    │  (付费后)    │ │  (按次付费)  │ │  (订阅)      │
    └─────────────┘ └─────────────┘ └─────────────┘
```

### 铁律

| 规则 | 说明 |
|------|------|
| **Hub→Spoke 单向** | 管理后台可以预览任何产品页(新标签页打开) |
| **Spoke→Hub 阻断** | 产品页绝对没有管理后台入口(连链接都没有) |
| **Spoke↔Spoke 有限互通** | 产品页之间可以交叉推荐(如QA答案底部"深入学习→录播课") |
| **公开入口独立** | 每个产品页有自己的公开URL,上线时通过微信/二维码分发 |

## 路由设计

```
Flask Routes:

# === 管理后台(老唐专属) ===
/                         → review.html (管理后台,默认入口)
/admin                    → review.html (显式入口)

# === 产品页面(公开/半公开) ===
/landing                  → landing.html (产品落地页,完全公开)
/qa                       → qa.html (AI问答助手页面)
/premium                  → premium_viewer.html (精品查看器,拖JSON)

# === 产品页面(计划上线,预置路由) ===
/course                   → course.html (线上录播课)        [Phase B]
/compliance               → compliance.html (合规自检工具)   [Phase B]
/daily                    → daily.html (政策变化日报)        [Phase B]
/templates                → templates.html (模板工具包)      [Phase B]

# === 静态资源 ===
/static/<path>            → web/templates/ 下的 CSS/JS/图片

# === API(不变) ===
/api/*                    → Flask API路由(不变)
```

## 管理后台"产品预览"菜单

在 review.html 的 header 区域(logo旁边或右上角),新增下拉菜单:

```html
<!-- 产品预览下拉 -->
<div class="product-nav">
  <button onclick="toggleProductMenu()">产品预览 ▾</button>
  <div id="productMenu" class="dropdown-menu" style="display:none">
    <a href="/landing" target="_blank">📄 产品落地页</a>
    <a href="/qa" target="_blank">🤖 AI问答助手</a>
    <a href="/premium" target="_blank">📦 精品查看器</a>
    <hr>
    <span class="menu-label">计划上线:</span>
    <a href="/course" target="_blank" class="planned">📚 线上录播课 <small>(即将上线)</small></a>
    <a href="/compliance" target="_blank" class="planned">✅ 合规自检 <small>(即将上线)</small></a>
    <a href="/daily" target="_blank" class="planned">📰 政策日报 <small>(即将上线)</small></a>
    <a href="/templates" target="_blank" class="planned">📋 模板工具包 <small>(即将上线)</small></a>
  </div>
</div>
```

### 设计要点
- 所有链接 `target="_blank"` — 新标签页打开,不打断管理后台工作
- "计划上线"的链接用灰色/虚线样式区分
- 计划页面的路由已预置,即使页面还没开发,也会显示"即将上线"占位
- 下拉菜单位于header右侧,不占用Tab空间

## 产品页间的交叉推荐逻辑

```
QA页面(/qa): 
  答案底部 → "深入学习: 相关课程" → /course
  答案底部 → "下载模板: 项目实施方案" → /templates

课程页面(/course):
  每课底部 → "有疑问?问AI助手" → /qa
  每课底部 → "下载配套模板" → /templates

日报页面(/daily):
  每篇日报 → "查看完整政策原文" → /qa?q=政策名
  每篇日报 → "检查你的项目是否受影响" → /compliance

模板页面(/templates):
  每个模板 → "看不懂?问AI" → /qa
  每个模板 → "需要合规检查?" → /compliance
```
