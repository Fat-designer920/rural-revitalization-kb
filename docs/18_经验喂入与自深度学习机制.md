## 一、经验文档喂入

### 喂到哪里

```
把你的经验文档(.docx/.pdf/.txt/.md)直接放入:
  data/experience_inbox/

放入后不需要做任何操作——系统自动检测、自动处理。
```

### 自动处理流程

```
老唐放入文件 → data/experience_inbox/
      │
      ▼ (自动检测,每5分钟扫描一次)
  预处理: 文件读取+OCR → .md缓存
      │
      ▼ (自动,V4-Pro深度提取)
  知识提取: 标记为 doc_origin='laotang_experience'
      │  extraction_prompt 使用 EXPERIENCE_EXTRACT_PROMPT(老唐经验专用)
      │  提取维度: 反常识洞察/操盘方法/踩坑记录/客户沟通话术/政策真实理解
      ▼
      ▼ (自动)
  自动确认: 老唐经验KP review_status='confirmed' (高信任)
      │
      ▼ (自动)
  精品判定: 优先提升为 premium(护城河内容)
      │
      ▼ (自动)
  入库: 进入QA检索池,可被用户查询到
```

### 与普通爬虫内容的区别

| 属性 | 爬虫内容 | 老唐经验 |
|------|---------|---------|
| doc_origin | 'crawled' | **'laotang_experience'** |
| 信任级别 | 需QC验证 | **直接confirmed** |
| 精品判定 | 标准判定 | **优先premium** |
| 保鲜周期 | 90天 | **365天**(经验不过时) |
| 提取精度 | V4-Pro标准 | **V4-Pro深度**(更仔细) |

## 二、CEO自深度学习调度机制

### 核心原理: 四环飞轮

```
         ┌──────────────────────────┐
         │   1.感知(Perceive)        │
         │   扫描系统状态+Agent状态   │
         │   +新数据+质量指标        │
         └──────────┬───────────────┘
                    ▼
         ┌──────────────────────────┐
   ┌─────│   2.学习(Learn)           │─────┐
   │     │   发现差距→研究方案        │     │
   │     │   Agent分析+SkillScout    │     │
   │     │   +趋势分析+竞品对比       │     │
   │     └──────────┬───────────────┘     │
   │                ▼                     │
   │     ┌──────────────────────────┐     │
   │     │   3.进化(Evolve)          │     │
   │     │   升级Agent/调整架构       │     │
   │     │   /优化管道/整合Skill     │     │
   │     │   → 所有改动自动执行       │     │
   │     └──────────┬───────────────┘     │
   │                ▼                     │
   │     ┌──────────────────────────┐     │
   │     │   4.验证(Validate)        │     │
   │     │   评估改进效果             │◄────┘
   │     │   对比基准指标             │
   │     │   差距缩小?→继续优化       │
   │     └──────────┬───────────────┘
   │                ▼
   │     ┌──────────────────────────┐
   └─────►   回到1.感知              │
         │   (新一轮循环)            │
         └──────────────────────────┘
```

### CEO调度机制

```
每5分钟: CEO自主循环
  ┌─ 感知: 扫描DB(KP增长/关系变化/Agent状态/KPI指标)
  ├─ 学习: CEO.deep_think()分析趋势+差距
  │        Agent进化师: 评估全部Agent评分
  │        SkillScout: 搜索最新工具
  │        市场拓展部: 监控竞品动态
  ├─ 进化: 自动触发改进
  │        低分Agent → 升级
  │        知识缺口 → 通知爬虫
  │        架构问题 → 提出方案
  │        Skill可用 → 调用SkillScout整合
  └─ 验证: 对比上一轮指标
           质量提升? → 继续
           质量下降? → 回滚+诊断
```
