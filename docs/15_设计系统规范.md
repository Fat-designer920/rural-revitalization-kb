# 设计系统规范 v1.0

> 来源: Apple HIG + Google Material + MUJI + 宋代水墨美学
> 原则: 清新淡雅,不花哨,不堆砌,留白≥40%,每个元素有存在的理由

---

## 一、色彩系统(20个Token)

### 来源: 宋代水墨"墨分五色" + MUJI自然色系 + 乡村振兴土地色

```
水墨系(文字):                      土地系(品牌):
焦 #1A1A1A  — 主标题               深绿 #1A5632  — 主品牌色(可信赖)
浓 #333333  — 副标题               金色 #C8922B  — 强调色(温暖)
重 #666666  — 正文                 暖灰 #F5F0E8  — 纸张背景
淡 #999999  — 辅助文字             浅绿 #E8F5F2  — 卡片底色
清 #CCCCCC  — 禁用/占位
```

### CSS Token定义

```css
:root {
  /* === 水墨文字 === */
  --ink-900: #1A1A1A;   /* 主标题,最高强调 */
  --ink-700: #333333;   /* 副标题,次级强调 */
  --ink-500: #666666;   /* 正文 */
  --ink-300: #999999;   /* 辅助文字,时间戳 */
  --ink-100: #CCCCCC;   /* 禁用,占位符 */

  /* === 土地品牌 === */
  --land-green:       #1A5632;   /* 主品牌色: 按钮,链接,强调 */
  --land-green-light: #E8F5F2;   /* 绿色浅底: 卡片,选中态 */
  --land-green-hover: #154828;   /* 绿色深色: hover */
  --land-gold:        #C8922B;   /* 强调色: 重要标签,价格 */
  --land-gold-light:  #FFF8ED;   /* 金色浅底: 提示条 */
  --land-warm:        #F5F0E8;   /* 纸张背景色(全局底色) */
  --land-warm-dark:   #EBE4D8;   /* 纸张深色: hover,分割线 */

  /* === 功能色 === */
  --red-500:    #C5281C;   /* 错误,删除,高风险 */
  --red-light:  #FFEFEE;   /* 红色浅底 */
  --amber-500:  #B85C00;   /* 警告,中风险 */
  --amber-light:#FFF9F0;   /* 黄色浅底 */
  --green-500:  #2D7B5F;   /* 成功,通过,低风险 */
  --green-light:#EDF5F1;   /* 绿色浅底(与品牌绿区分) */

  /* === 基础 === */
  --white:      #FFFFFF;   /* 卡片,弹窗 */
  --border:     #E5E5EA;   /* 分割线,边框 */
  --border-light:#F2F2F7;  /* 极细分割 */
}
```

### 颜色使用规则

| 规则 | 说明 |
|------|------|
| 主按钮 | `bg:--land-green, color:--white` |
| 次按钮 | `bg:transparent, border:--land-green, color:--land-green` |
| 链接 | `color:--land-green, underline` |
| 正文 | `color:--ink-500` (不是纯黑#000) |
| 页面底色 | `bg:--land-warm` (不是纯白#FFF) |
| 卡片底色 | `bg:--white` (浮在--land-warm之上) |
| 禁用/占位 | `color:--ink-100` |

## 二、字体系统(10个Token)

### 字体栈

```css
--font-sans: "PingFang SC", "Microsoft YaHei", "Noto Sans SC",
             system-ui, -apple-system, sans-serif;
--font-mono: "SF Mono", "Cascadia Code", Consolas, monospace;
```

### 字号+行高(8dp节奏)

```css
--text-xs:   12px;   /* 标签,脚注 */
--text-sm:   14px;   /* 辅助文字(最小,WCAG要求≥14px) */
--text-base: 16px;   /* 正文(移动端最小,桌面端默认) */
--text-lg:   20px;   /* 小标题 */
--text-xl:   24px;   /* 中标题 */
--text-2xl:  32px;   /* 大标题,hero */
--text-3xl:  40px;   /* 超大标题(仅landing hero) */

--leading-tight:  1.3;   /* 标题 */
--leading-normal: 1.75;  /* 正文(中文需要比英文大的行高) */
--leading-relaxed:2.0;   /* 长文,政策原文 */
```

### 字重

```css
--font-normal:  400;   /* 正文 */
--font-medium:  500;   /* 副标题 */
--font-semibold:600;   /* 标题,强调 */
```

## 三、间距系统(8dp网格)

```css
--space-xs:   4px;    /* 紧密关联元素间(图标+文字) */
--space-sm:   8px;    /* 相关元素间(标签组) */
--space-md:   16px;   /* 默认间距(卡片内padding,段落间距) */
--space-lg:   24px;   /* 区块间距(卡片间,section间) */
--space-xl:   32px;   /* 大间距(页面padding) */
--space-2xl:  48px;   /* 超大间距(hero上下) */
--space-3xl:  64px;   /* 极大间距(仅landing section间) */
```

### 使用规则

```
页面padding: --space-xl (32px, mobile) → --space-2xl (48px, desktop)
卡片padding: --space-lg (24px)
卡片间距:    --space-lg (24px)
段落间距:    --space-md (16px)
按钮内padding: --space-sm+--space-md (8px+16px)
```

## 四、圆角系统(4个Token)

```css
--radius-sm:  4px;    /* 小元素: 标签,徽章 */
--radius-md:  8px;    /* 默认: 按钮,输入框,小卡片 */
--radius-lg:  16px;   /* 大: 卡片,弹窗,QA回答框 */
--radius-full:9999px; /* 圆形: 头像,开关 */
```

### 使用规则

| 元素 | 圆角 | 理由 |
|------|------|------|
| 按钮 | 8px | 温和,可点击感 |
| 输入框 | 8px | 与按钮一致 |
| 卡片 | 16px | 柔和,明确是卡片 |
| 弹窗/模态 | 16px | 与卡片一致 |
| 标签/徽章 | 4px | 小巧 |
| QA回答气泡 | 16px(左)+4px(右) | 对话感 |

## 五、阴影系统(5级海拔)

```css
/* 海拔0: 无阴影(平面元素) */
--shadow-none: none;

/* 海拔1: 极低(卡片hover,按钮hover) */
--shadow-sm: 0 1px 3px rgba(0,0,0,0.06);

/* 海拔2: 低(卡片默认,下拉菜单) */
--shadow-md: 0 4px 12px rgba(0,0,0,0.06);

/* 海拔3: 中(弹窗,模态) */
--shadow-lg: 0 8px 24px rgba(0,0,0,0.08);

/* 海拔4: 高(极少使用) */
--shadow-xl: 0 16px 48px rgba(0,0,0,0.10);
```

### 使用规则

| 元素 | 海拔 | 理由 |
|------|------|------|
| 正文,段落 | 0 | 不需要 |
| QA回答卡片 | 2 | 浮在纸张背景上 |
| 页面导航 | 2 | sticky悬浮 |
| 下拉菜单 | 2 | 浮在内容上 |
| 弹窗 | 3 | 最高层 |
| 不用的: 大面积阴影,彩色阴影,多层阴影堆叠 | — | 宋代美学: 克制 |

## 六、组件规范(18个)

### 1. 按钮

```
主按钮: bg:--land-green, color:--white, radius:--radius-md
        padding:8px 24px, font:16px/500
        hover:bg:--land-green-hover, 150ms scale(0.98→1.0)
        disabled:opacity:0.4

次按钮: bg:transparent, border:1px solid --land-green
        color:--land-green, 其他同主按钮

文字按钮: color:--land-green, 无背景无边框, hover显示下划线
```

### 2. 输入框

```
height:48px(移动端友好,手指不误触)
border:1px solid --border, radius:--radius-md
padding:0 16px, font:16px
focus:border:--land-green, box-shadow:none(不用发光效果——宋代美学克制)
placeholder:color:--ink-100
```

### 3. 卡片

```
bg:--white, radius:--radius-lg, shadow:--shadow-md
padding:24px(--space-lg)
margin-bottom:24px(--space-lg)
无边框(靠阴影和间距区分)
```

### 4. 导航栏

```
sticky top-0, height:52px
bg:rgba(255,255,255,.85) + backdrop-filter:blur(20px) (Apple HIG)
border-bottom:0.5px solid --border(不是1px——MUJI极细)
```

## 七、组件设计原则

1. **减法优先**: 每个组件先做功能最少版本,需要时再加,不提前加
2. **MUJI法则**: 组件默认无边框,用间距和背景色区分
3. **8dp验证**: 所有尺寸必须是8的倍数(除了1px分割线)
4. **320px测试**: 每个组件在320px宽度下必须可用
5. **无JS依赖**: 组件的视觉效果纯CSS,JS只处理交互逻辑
