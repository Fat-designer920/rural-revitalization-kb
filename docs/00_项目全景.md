## 技术栈

- 运行环境：Windows + Python 3.8+，便携版
- AI 引擎：DeepSeek API(V4-Pro 主链 + V4-Flash 辅助)+ 硅基流动(OCR + 镜像兜底)
- **Agent体系**: agents/独立目录,~50个BaseAgent思考实体,10部门,每个独立调用AI API,可自我进化
- **硬件加速**: ONNX Runtime DirectML(NPU/GPU统一加速,814K KPs/s)
- **CEO决策**: V4-Pro深度战略推理 + meeting_engine七步会议协议
- 存储:SQLite(28 张业务表 + 37 条索引)
- 界面：Flask 本地 Web 管理后台 + 独立朋友试用产品页 /qa
- 入口：`启动后台.bat` / `首次安装.bat`

## 双 API 架构

| API | 用途 | 模型 |
|-----|------|------|
| DeepSeek | 知识提取 / 打磨 / 分类 / 质检 / 预分析 / 关系判别 / 问答 | deepseek-v4-pro / deepseek-v4-flash |
| 硅基流动 | 扫描件 PDF/图片 OCR + V4-Pro 镜像兜底(跨厂商冗余) | Qwen/Qwen2.5-VL-72B-Instruct + V4-Pro镜像 |

## 数据流

```
预处理: 原始文件 → 读取/OCR → .md 缓存(processing) + DB 记录
提取:   优先读 .md 缓存 → 并行双模型提取(V4-Flash 全覆盖 + V4-Pro 深挖核心段 → 合并去重)
        → L0 降级: V4-Pro 镜像兜底(硅基)/ F057 截断(若 partial>=1)
        → 跨段补漏: 1 轮闭环 → 入库 → 归档 completed
质量链: 入库质检三级降级(F058) → 政策校验 → 关系分析 → 人工审核 → 保鲜
```
